# MY CAR — лендинг 5D-ковриков, Якутск

Одностраничный сайт для **MY CAR** (@my.car_ykt): 5D-коврики, автоателье, цех. Якутск, ул. Дежнёва, 30, 1 этаж, офис 6.

## Структура
```
index.html          — страница (10 блоков) + JSON-LD (LocalBusiness, Offer, FAQPage)
css/style.css       — стили, адаптив 320px → 1920px
js/main.js          — бургер-меню, слайдер отзывов, до/после, конструктор, видео-модалка, форма → WhatsApp, ленивая карта
img/                — фото из видео клиента (WebP, 720px и 360px), логотип, иконки, og.jpg
video/              — ролики H.264 540p с faststart; звук оставлен только в before-after.mp4 и process.mp4
robots.txt, sitemap.xml, llms.txt, site.webmanifest, .htaccess
SEO-keywords.md     — семантическое ядро и что где использовано
```

## Блоки
1. Hero: 5D, цена 9 000 ₽, −30%, видео в «телефоне»
2. Цены: 2 ряда / багажник / 3 ряда, подарки, рассрочка, доставка
3. «Было / Стало»: шов можно перетаскивать, есть видео со звуком
4. Направления: 5D собственного производства, EVA/TPE, магазин, съёмная тонировка
5. Конструктор: цвет кожи, нити и рисунок, вариант уходит в заявку
6. Цех: процесс пошива в 6 шагов и видео со звуком
7. Работы: 12 автомобилей, видео открывается в модальном окне
8. Отзывы: слайдер со свайпом, стрелками, точками и автопрокруткой
9. FAQ (размечен schema FAQPage)
10. Заявка → WhatsApp (сообщение уже заполнено), контакты, Яндекс.Карта

## Перед публикацией
- **Отзывы.** Тексты в блоке «Отзывы» — шаблоны для показа слайдера. Замените их реальными отзывами клиентов из Директа, WhatsApp или 2ГИС (index.html, `#revSlider`).
- **Домен.** Замените `mycar-ykt.ru` на реальный в index.html, robots.txt, sitemap.xml и llms.txt.
- WhatsApp: номер записан в международном формате `79142619326`, потому что с «8» ссылки WhatsApp не открывают чат. Меняется в `js/main.js` (`WA_PHONE`) и в ссылках index.html.
- Хостинг: любой статический (Beget, Timeweb, Netlify, GitHub Pages). Для Apache приложен `.htaccess` (gzip и кэш).

## Совместимость
Chrome, Safari (iOS 13+), Firefox, Edge, Samsung Internet, Яндекс.Браузер. Видео с `playsinline`, iOS не открывает их на весь экран. Учтены safe-area для iPhone и `100svh/100dvh`, предусмотрены fallback-значения.
